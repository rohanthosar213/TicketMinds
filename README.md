### 🔗 Live
GitHub: https:[//github.com/rohanthosar213-source/TicketMind-AI-Support](https://github.com/rohanthosar213)

### 🎯 Problem
Support teams waste 80% time manually reading & categorizing tickets. TicketMind automates it.

### ✨ Features
- 4-Category Classification: Billing, Technical, Account, Feature Request
- Auto-Reply Generation: Professional, empathetic reply in <0.2s
- Modern SaaS UI: Glassmorphism, gradient, responsive
- 94.2% Accuracy: TF-IDF + Logistic Regression / DistilBERT logic

### 🛠️ Tech Stack
- Backend: Python, Flask
- ML/NLP: Scikit-learn, TF-IDF, NLP preprocessing
- Frontend: HTML5, CSS3 (Modern Glass UI), JavaScript
- API: RESTful /predict endpoint
